# Language Learning Game Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A double-click-to-open, browser-only language game that loads the user's xlsx/csv (Source, Target, Date, Category by position) and offers Cloze, Multiple Choice, Pair Match and Daily Word, with Leitner scheduling, study sets, XP/streak/medals and JSON progress export.

**Architecture:** Classic `<script>` files sharing one global `LG` namespace (no modules, no build). Pure logic lives in `js/core/*` and is unit-tested by an in-repo runner that works both in `tests.html` and under plain `node` (dev verification only — no npm packages). UI lives in `js/ui/*` and renders plain DOM into `#app`.

**Tech Stack:** HTML, CSS custom properties, vanilla JS (ES2020, classic scripts), SheetJS 0.20.3 vendored at `lib/xlsx.full.min.js`, `Intl.Segmenter`, `localStorage`, IndexedDB.

**Spec:** `docs/superpowers/specs/2026-10-26-language-game-design.md`

## Global Constraints

- The app must work by double-clicking `index.html` (`file://`). No npm, no build, no server, no install for the user.
- No `type="module"`, no `import`/`export`, no `fetch()` of local files. Every file is a classic script wrapped as `(function (LG) { ... })(globalThis.LG = globalThis.LG || {});`.
- No runtime CDN. SheetJS is the only third-party file, pinned at 0.20.3, in `lib/`.
- Columns are read by position: 1 Source, 2 Target, 3 Date, 4 Category. Never by header name.
- Target is the language being learned. Cloze and Daily Word always use Target. The direction toggle only swaps prompt/answer in Multiple Choice and Pair Match.
- Every locale-sensitive call gets the column's language code: `toLocaleLowerCase(lang)`, `new Intl.Segmenter(lang, …)`, `localeCompare(x, lang)`.
- Text dates are day-first: `DD-MM-YYYY` (primary), `DD.MM.YYYY`, `DD/MM/YYYY`, plus `YYYY-MM-DD`. UI shows `DD-MM-YYYY`.
- Look: calm, functional, not childish. Neutral palette, one accent color, system font stack, no emoji/mascots/confetti/sound. Light and dark themes both first-class, via CSS custom properties.
- Target browsers: current Chrome and Edge on Windows.
- UI copy in English.
- Commit messages: plain conventional messages, **no attribution trailers or "generated by" lines of any kind**.

## Review Focus

1. **CSV saved by Excel as "CSV (Comma delimited)" on Turkish/Polish Windows is not UTF-8** (Windows-1254 / Windows-1250). Expected: letters like ı, ğ, ş, ł, ź come through correctly, and the import summary names the encoding used. → Task 2, `decodeCsvBytes` tests.
2. **Excel auto-converts cells**: numeric Source/Target cells (e.g. `42`) and date cells arrive as numbers; CSV dates must stay text and not be re-interpreted month-first. Expected: `42` becomes `"42"`, `13-12-2025` in CSV becomes 13 December. → Task 2, `rowsToDataset` and `sheetRowsFromCsvText` tests.
3. **Same category typed differently** (`Food`, `food `). Expected: one category, first spelling kept. → Task 2 test `categories merge case-insensitively`.
4. **Blank word appears more than once in a sentence.** Expected: exactly one occurrence (the chosen index) is blanked, and typing the word counts as correct. → Task 3 test `pickBlank returns a single occurrence index`.
5. **Corrupt or missing saved state** (manual edit, partial write, older shape). Expected: the app starts with defaults plus a visible warning instead of a blank page, and missing keys are filled from defaults. → Task 7 `loadState` tests.

### Task 2: Dates, hashing and import

**Files:**
- Create: `js/core/rng.js`, `js/core/dates.js`, `js/core/importer.js`, `tests/dates.test.js`, `tests/importer.test.js`
- Modify: `tests/manifest.js` (append the three src files and two test files), `index.html` (script tags)

**Interfaces:**
- Consumes: `LG.text.normalizeCell`, `LG.text.lower`, global `XLSX`.
- Produces:
  - `LG.rng.cyrb53(str, seed = 0) → number`; `LG.rng.seeded(seed: number) → () => number in [0,1)` (mulberry32); `LG.rng.shuffle(arr, rand = Math.random) → new array` (Fisher–Yates).
  - `LG.dates.parseDate(v: Date|number|string) → 'YYYY-MM-DD' | null` — Date → its local Y-M-D; number in `[1, 2958465]` → Excel serial via `XLSX.SSF.parse_date_code`; string → `^(\d{1,2})[-./](\d{1,2})[-./](\d{4})$` day-first, or `^(\d{4})-(\d{2})-(\d{2})$`; rejects impossible dates (31-02).
  - `LG.dates.formatDate(iso) → 'DD-MM-YYYY'` (`''` for null); `LG.dates.todayISO(now = new Date()) → 'YYYY-MM-DD'` (local); `LG.dates.addDaysISO(iso, n) → iso`.
  - `LG.importer.itemId(source, target) → string` — `'i' + cyrb53(normalizeCell(source) + '\u0001' + normalizeCell(target)).toString(36)`.
  - `LG.importer.decodeCsvBytes(bytes: Uint8Array) → { text, encoding }` — try `TextDecoder('utf-8', { fatal: true })`; on failure decode as `windows-1254` and `windows-1250` and pick the one with more hits in its own letter set (1254: `ğĞşŞıİ`, 1250: `ąĄęĘłŁńŃśŚźŹżŻ`), ties → `windows-1254`. Strip a leading BOM.
  - `LG.importer.sniffDelimiter(text) → ',' | ';' | '\t'` — counts each in the first line, ignoring characters inside double quotes; most frequent wins, default `,`.
  - `LG.importer.sheetRowsFromCsvText(text) → any[][]` — `XLSX.read(text, { type: 'string', raw: true, FS: sniffDelimiter(text) })`, first sheet, `sheet_to_json(ws, { header: 1, raw: true, defval: '' })`.
  - `LG.importer.sheetRowsFromXlsx(buf: ArrayBuffer) → any[][]` — `XLSX.read(buf, { type: 'array' })`, first sheet, same `sheet_to_json` options.
  - `LG.importer.readFile(file: File) → Promise<{ rows, encoding }>` — `.csv` → bytes → `decodeCsvBytes` → `sheetRowsFromCsvText`; otherwise `sheetRowsFromXlsx`, encoding `'xlsx'`. Browser-only, no unit test.
  - `LG.importer.rowsToDataset(rows) → { items: Item[], summary: { loaded, headerSkipped, skippedEmpty, duplicates, badDates, categories: string[] } }` — header rule: row 0 skipped when its column-3 cell is non-empty and `parseDate(row[2])` is null (an empty date cell keeps the row as data, so a headerless file without dates loses nothing); cells via `normalizeCell`; empty category → `'Uncategorized'`; categories merged case-insensitively (`lower(…, undefined)`), first spelling wins; duplicates by `itemId`; `badDates` counts non-empty date cells that fail to parse.

### Task 3: Words — sentence/term, rarity, cloze blanks, hints, filters

**Files:**
- Create: `js/core/words.js`, `tests/words.test.js`
- Modify: `tests/manifest.js`, `index.html`

**Interfaces:**
- Consumes: `LG.text.*`.
- Produces:
  - `LG.words.MIN_SENTENCE_TOKENS = 4`
  - `LG.words.kindOf(target, lang) → 'sentence' | 'term'`
  - `LG.words.buildRarity(items, lang) → Map<string, number>` — document frequency of `lower(token)` over `item.target`, counting each word once per item.
  - `LG.words.clozeCandidates(target, rarity, lang) → Array<{ text, index }>` — up to 3. Eligible: length ≥ 4 (≥ 2 if `isDenseScript`), not `^\p{N}+$`. Sort by rarity asc, then length desc, then index asc. One entry per distinct lowercased word (first occurrence). If none eligible: `[longest token]` (first if tied).
  - `LG.words.pickBlank(item, entry, rarity, lang) → { text, index }` — if `entry.pin` matches (lowercase) a token, that token's first occurrence; else `candidates[(entry.rot || 0) % candidates.length]`. The caller increments `rot` (Task 9 `LG.play.advanceRotation`).
  - `LG.words.hintText(word, level) → string` — 0 `''`; 1 first letter + `'…'`; 2 first letter then `' _'` per remaining letter; 3 letters at even positions shown, odd positions `_`, space-joined.
  - `LG.words.specialLetters(items, lang) → string[]` — distinct lowercase letters (`\p{L}`) in targets outside `a–z`, sorted with `localeCompare(…, lang)`.
  - `LG.words.filterItems(items, { dateFrom, dateTo, categories }) → Item[]` — inclusive ISO bounds; when either bound is set, items with `date === null` are excluded; empty/absent `categories` means all.
  - `LG.words.groupOptions(items) → { categories: [{ name, count }], dates: [{ date, count }] }` — categories by `localeCompare`, dates newest first; null dates not listed.

### Task 21: Missed words come back in the same round, and "practice the words you missed"

**Why (user):** "Imagine I can't know some words. Then I want to work on those again." Today a missed word only returns in a later round. The user approved two additions:
1. In-round relearning: a missed word goes to the end of the round and keeps coming back until it is answered right once.
2. A "Practice the N words you missed" button on the summary.

**Rules (controller rulings — binding):**
- Only the **first** answer to a word in a round counts. That answer:
  - goes through `LG.play.answerPrompt` as now (box, due, revenge pile, XP, combo, study set),
  - decides the word's correct/almost/wrong tally in the summary.
- **Repeats** of a missed word in the same round are practice only:
  - No `answerPrompt` call, so no box, revenge, XP or combo change.
  - A wrong repeat goes to the end of the queue again. A correct (or almost) repeat leaves the round.
- Applies to **Review, Revenge and Leitner** modes in **Cloze, Multiple Choice and Flashcards**.
  - **Study set** keeps its existing behaviour (`LG.study` already re-queues misses); don't double-requeue there.
  - **Pair Match** and **Daily Word** are unchanged.
- A word repeats at most **3 times** after its first miss. After that it leaves the round, so a session always ends.

**Core — new `js/core/round.js` (`LG.round`)**, registered in `tests/manifest.js` and `index.html` after `study.js`, with tests in `tests/round.test.js`:
- `create(ids) → Round`, where Round is `{ queue: id[], first: { [id]: 'correct'|'almost'|'wrong' }, repeats: { [id]: number }, total: number }` and `total = ids.length`.
- `current(r) → id | null`: the head of the queue.
- `isFirst(r, id) → boolean`: true if the word has not been answered yet in this round.
- `record(r, id, result) → Round`, which returns a new object:
  - On a first answer, set `first[id] = result`.
  - Then: if `result === 'wrong'` and `(repeats[id] || 0) < 3`, move the id to the end of the queue and increment `repeats[id]`. Otherwise remove it from the queue.
  - On a repeat answer, `first` is unchanged and the same queue rule applies.
- `missed(r) → id[]`: ids whose first answer was `'wrong'`, in first-answer order.
